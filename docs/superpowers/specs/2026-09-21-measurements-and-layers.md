# Измерения и выбор слоя

## Цель

Исправить интерактивность слоёв на странице результатов анализа и заменить заглушку `/calculations` страницей измерений на моковых данных.

## Слои результатов

- Панель остаётся сворачиваемой и открыта по умолчанию.
- Слои отображаются в одной `Radio.Group`: выбран ровно один слой, выбранное значение хранится в локальном state компонента.
- Нажатие на всю строку слоя выбирает его; radio остаётся доступным с клавиатуры и имеет понятную подпись для screen reader.

## Страница `/calculations`

- Заголовок «Измерения», краткое описание и кнопка «Создать измерение».
- Поиск по названию, фильтры даты начала и даты конца по полю даты события, сброс фильтров. Границы включительны; при некорректном диапазоне список пуст и показано состояние «Ничего не найдено».
- Таблица Mantine с локальной сортировкой по дате события, региону, типу события и площади. По умолчанию это дата события по убыванию; колонка действия «Открыть» не сортируется.
- Пагинация после таблицы по 8 записей. Фильтрация, сортировка и пагинация вычисляются из одного массива моковых записей; состояние страницы сбрасывается после изменения фильтра или сортировки. Для пустого результата таблица показывает явное пустое состояние без пагинации.
- Кнопка «Открыть» выбирает запись и открывает drawer справа. В нём показаны изображение-превью, параметры записи и отключённая (`disabled`) кнопка «Посмотреть» без навигации до появления маршрута `/analysis/result/:id`.

## Архитектура

- `pages/calculations/model/mock.ts` хранит тип и набор моковых записей. У каждой записи есть стабильный `id`, название, дата события в ISO-формате, регион, тип, площадь и путь к изображению-превью с визуальной заглушкой при ошибке загрузки.
- `pages/calculations/ui` содержит страницу и презентационные секции таблицы/предпросмотра, используя только Mantine и уже доступные Tabler-иконки.
- Состояние UI (фильтры, сортировка, текущая страница, открытый drawer и выбранная запись) находится в композиции страницы. Отфильтрованный и отсортированный список не дублируется в state.

## Проверка

- TypeScript typecheck и production build.
- Ручная проверка переключения единственного слоя, поиска, фильтров дат, сортировки, пагинации и drawer.
